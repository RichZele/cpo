# The CPO paper, as far as the course has reached

*CPO: a modular ontology for lighting information in building projects* is the worked example of TADS23, written
with the course's report template. Use it as an example of what your own report can look like.

This version goes as far as Lecture 4c: the introduction, the literature review, the method, the ontology with its
modules, the composed ontology and its spanning axioms, the review, publication and the first tests (ABID-Mo steps
1 to 10). The Discussion and the Conclusions are added when the course reaches them, after the graph database,
SHACL validation and the analysis back to Revit.

| File | What it is |
|---|---|
| [`cpo-paper.pdf`](cpo-paper.pdf) | The paper, ready to read |
| `main.tex` | The LaTeX source (elsarticle, Elsevier numbered references). Compile with pdfLaTeX, the Overleaf default. |
| `references.bib` | The references |
| `figures/` | The process map, the system architecture, the PRISMA diagram and the Graffoo diagrams |

To open it in Overleaf: download this folder, zip `main.tex`, `references.bib` and `figures/`, and upload the zip
with New Project > Upload Project.
