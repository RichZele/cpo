# Reference documentation (HTML, made with WIDOCO)

One website per ontology, generated from the Turtle files with [WIDOCO](https://github.com/dgarijo/Widoco): every
class and property with its label, definition, domain and range, and a WebVOWL diagram. Browsers that open
`https://w3id.org/cpo` are redirected here.

| Ontology | Documentation |
|---|---|
| `https://w3id.org/cpo` (composed, covers every term) | [doc/cpo](https://richzele.github.io/cpo/doc/cpo/) |
| `https://w3id.org/cpo/project` | [doc/project](https://richzele.github.io/cpo/doc/project/) |
| `https://w3id.org/cpo/product` | [doc/product](https://richzele.github.io/cpo/doc/product/) |
| `https://w3id.org/cpo/requirement` | [doc/requirement](https://richzele.github.io/cpo/doc/requirement/) |

Open the links above: GitHub shows the HTML files here as source, not as pages.

For the design of each module, with its schema diagram, the axioms in description logic, their explanations and the
competency questions, see the PDFs in [module-docs-pdf/](../module-docs-pdf/).
